1. Трьохрівневий захист форми (Frontend + Backend)
Валідація імені «на льоту»: JavaScript-слухач input миттєво видаляє будь-які символи, крім українських та англійських літер, блокуючи введення цифр чи спецсимволів прямо під час набору. На сервері PHP робить фінальну жорстку перевірку регулярним виразом preg_match із прапором /u для коректної роботи з UTF-8.
Розумна маска телефону: Інтегровано JS-маску українських операторів +38 (0XX) .... На бекенді PHP очищує номер від зайвих знаків, перевіряє довжину (рівно 12 цифр із 380) та звіряє код оператора із масивом реальних мобільних мереж України для захисту від фейкових номерів.
Антиспам без капчі: Реалізовано дворівневу невидиму пастку для ботів:
Honeypot: Приховане через CSS поле, яке заповнюють лише спам-роботи. Якщо воно не пусте — запит блокується.
Time Trap: Перевірка часу заповнення форми. Якщо дані надіслано швидше ніж за 3 секунди з моменту завантаження сторінки — система відхиляє запит як автоматичний.
2. Пряма інтеграція з CRM SalesDrive
Оскільки розробка ведеться на локальному сервері із закритими портами, налаштовано автономний обробник даних. При надсиланні форми дані миттєво передаються через Standard Web-Form API безпосередньо до SalesDrive, де автоматично створюється картка нової заявки.
