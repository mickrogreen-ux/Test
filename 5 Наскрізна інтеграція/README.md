На фронтенді (JS): Слухач подій input миттєво видаляє будь-які символи, що не є літерами українського чи англійського алфавіту прямо під час введення. Користувач фізично не зможе ввести цифру.

На бекенді (PHP): Регулярний вираз preg_match("/^[a-zA-Zа-яА-ЯіІїЇєЄґҐ\s]+$/u") робить фінальну жорстку перевірку (прапор /u обов'язковий для коректної роботи з кирилицею в UTF-8).

Маска та валідація українських операторів:
Чиста JS-маска автоматично форматує ввід у вигляд +38 (0XX) XXX-XX-XX.

На сервері PHP очищує номер від дужок та дефісів, перевіряє довжину (рівно 12 цифр, починаючи з 380), а також звіряє код оператора (наприклад, 67, 50, 93) із заздалегідь підготовленим масивом реальних кодів українських мобільних мереж.

Захист від спаму БЕЗ капчі (Дворівневий антиспам):
Honeypot (Горщик з медом): Створено поле website_hp, яке через CSS повністю сховане від очей звичайних користувачів. Проте спам-боти сканують чистий HTML-код форми і автоматично заповнюють абсолютно всі поля підряд. Якщо поле заповнене — це 100% робот, і PHP блокує запит.

Валідація «на льоту»: Додано JavaScript-маску телефону операторів України +38 (0XX) XXX-XX-XX та автоматичну заборону на введення цифр чи спецсимволів у поле імені.
Серверна безпека: Реалізовано перевірку кодів мобільних операторів на рівні PHP (захист від неіснуючих номерів).
Антиспам без капчі: Інтегровано дворівневу невидиму пастку для ботів (метод Honeypot + часовий ліміт заповнення форми).
2. Налаштовано наскрізний каскад передачі даних (Каскадний API-обробник)
Оскільки розробка та тестування ведуться на локальному сервері, використання стандартних зовнішніх вебхуків від CRM було б технічно неможливим через закриті порти комп'ютера. Створено автономний послідовний алгоритм:
Етап 1: При надсиланні форми дані миттєво йдуть через Standard Web-Form API до SalesDrive, де успішно створюється картка нової заявки.
Етап 2 (за подією успіху): Як тільки скрипт отримує підтвердження від CRM, він автоматично (через REST API) передає контакт покупця далі в Діловод (довідник «Контрагенти»).
Результат: Інтеграція повністю готова до роботи. Дані синхронізуються автоматично в обох системах за один клік користувача. При перенесенні скрипту на реальний хостинг код не потребуватиме додаткових налаштувань.
