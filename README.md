# Тестове завдання (Двосторінковий сайт )

Репозиторій містить комплексне виконання двох частин тестового завдання: верстку двосторінкового сайту з Figma та написання скрипту автоматизації Excel.

---

 Вебсайт (Pixel-Perfect верстка з Figma)
Двосторінковий вебсайт успішно перенесений із дизайн-макета Figma у чистий код, адаптований під мобільні пристрої та опублікований на хостингу.


* **Локація файлів:** Головна сторінка (`index.html`), друга сторінка та файли стилів розташовані в корені репозиторію для коректної роботи хостингу.

### Особливості верстки:
- **Дві сторінки**: Повністю реалізовано структуру та навігацію між сторінками сайту.
- **Figma To Code**: Точне перенесення дизайну (відступи, шрифти, кольорова гама, сітки) відповідно до макета.
- **Адаптивність**: Сайт коректно відображається на смартфонах, планшетах та десктопах.
