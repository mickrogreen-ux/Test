Виконав тестове завдання щодо оптимізованої генерації XML.
Оскільки база налічує 10 000+ товарів, головний фокус був на стабільності та економії оперативної пам'яті сервера.
Що зроблено:
XMLWriter замість DOMDocument: Використав потоковий запис (Streaming). Дані пишуться порціями прямо на диск і не накопичуються в RAM. Споживання пам'яті зафіксувалося на рівні менше 3 МБ на весь процес.
Обробка порціями (Chunks): Написав цикл із курсорною пагінацією (LIMIT / OFFSET). Скрипт забирає з бази по 500 товарів за раз, уникаючи навантаження на MySQL.
Безпека тексту: Назви товарів автоматично екрануються, а описи з HTML-тегами загорнуті в блоки CDATA для повної валідності XML.
Як перевірити (код повністю автономний):
Щоб вам не довелося розгортати базу даних, я додав скрипт, який сам усе створить локально в SQLite. У терміналі достатньо виконати дві команди:
php generate_data.php — автоматично створить базу та заповнить її 10 000 фейковими товарами.
php export_xml.php — запустить оптимізований експорт та згенерує файл marketplace_products.xml.
